Pengaturan Google Sheets

Info: Data tersimpan online di Google Sheets. Tanpa koneksi, data disimpan lokal di browser.

Langkah Setup:

1. Buka Google Sheets, buat Spreadsheet baru
2. Buat header di baris pertama:
id | namaInstansi | npsn | namaPIC | tipe | kategori | jumlahL | jumlahP | jumlahTotal | createdAt | updatedAt | groupId
3. Di dalam Spreadsheet itu (WAJIB dari dalam Sheet, bukan buka script.google.com terpisah), klik Extensions → Apps Script, hapus kode default, paste kode di bawah, lalu klik ikon Simpan
4. Klik Deploy → New deployment → pilih tipe Web app. Isi Execute as: Me, dan Who has access WAJIB Anyone (bukan "Anyone with Google account") — ini penyebab paling umum website gagal terhubung
5. Klik Deploy, izinkan akses (Authorize access), lalu salin URL Web App (diakhiri /exec) dan tempel di kolom bawah
Catatan: Setiap kali kode Apps Script diubah, ulangi Deploy → Manage deployments → ikon pensil → New version → Deploy, agar perubahan aktif
