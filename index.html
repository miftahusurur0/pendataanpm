Pengaturan Google Sheets

Info: Data tersimpan online di Google Sheets. Tanpa koneksi, data disimpan lokal di browser.
Impor dari sheet lama

Ambil data dari sheet lain di spreadsheet yang sama (header fleksibel). Data dengan id yang sudah ada dilewati.

Langkah Setup:

1. Buka Google Sheets, buat Spreadsheet baru (boleh kosong — kolom dibuat otomatis)
2. Di dalam Spreadsheet (WAJIB dari dalam Sheet), klik Extensions → Apps Script, hapus kode default, paste kode di bawah, lalu Simpan
3. (Opsional) Di menu spreadsheet: 🍽️ Sistem MBG → Inisialisasi — otomatis rename file jadi Pendataan PM, buat sheet Data PM + semua kolom header
4. Jika ada data di sheet lama: menu 🍽️ Sistem MBG → Impor data dari sheet lain
5. Deploy → New deployment → Web app. Execute as: Me, Who has access: Anyone (wajib)
6. Salin URL Web App (akhiran /exec), tempel di kolom bawah → Test → Hubungkan
Catatan: Setiap kali kode Apps Script diubah, ulangi Deploy → Manage deployments → ikon pensil → New version → Deploy, agar perubahan aktif
